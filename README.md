# WebSnabb — High-Performance Digital Agency Website

Official production repository for **WebSnabb**, a modern web design and development agency based at **Sandåsvägen 4, 22100 Mariehamn, Åland Islands**.

Website: [https://websnabb.github.io](https://websnabb.github.io)

---

## ✨ Features

- **Framework-Free Vanilla Architecture**: Built entirely with HTML5, Vanilla CSS3 (Variables, Grid, Flexbox), and Vanilla ES6+ JavaScript.
- **Multilingual Support (EN, SV, FI)**: Instant language switching without page reloads, persisted in `localStorage`.
- **Light & Dark Mode**: Respects system preferences (`prefers-color-scheme`) with smooth CSS transitions and state persistence.
- **Mobile-First UX**: Responsive design with standard desktop navigation and sticky bottom mobile navigation bar.
- **SEO & Accessibility Compliant**: WCAG AA focus outlines, ARIA attributes, JSON-LD Schema markup, Open Graph tags, canonical URL, `sitemap.xml`, and `robots.txt`.
- **High Performance**: Aiming for >95 scores across all Google Lighthouse categories.

---

## 🛠️ Tech Stack & Constraints

- **Language**: HTML5, Vanilla CSS, Vanilla JavaScript (ES6+)
- **Build Tools**: None required
- **Dependencies**: Zero npm dependencies or external JS frameworks
